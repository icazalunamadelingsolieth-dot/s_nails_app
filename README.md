# S Nails - Sistema de Gestión de Citas para Salón de Belleza

## Descripción breve
S Nails es una aplicación web SPA diseñada para optimizar y gestionar la reserva, edición y seguimiento de citas de un salón de belleza. Permite a los administradores administrar el catálogo de servicios, horarios y citas registradas.

## Integrantes del grupo
- Madeling Icaza

## Tecnologías utilizadas
- **Backend:** PHP 8.x, Laravel, MySQL / MariaDB (Laragon).
- **Frontend:** React, Vite, Axios, React Router.
- **Estilos:** Tailwind CSS / CSS personalizado (Paleta café-oscuro `#2b1e17` y dorado-crema `#e3c896`).

## Requisitos previos
- PHP >= 8.1
- Composer
- Node.js >= 18.x & npm
- Servidor local (Laragon, XAMPP o similar) con MySQL/MariaDB.
